# Frontend Engineering Mastery Notes

A structured, beginner-to-expert curriculum for becoming a teaching-level frontend engineer and preparing for top product-company interviews.

## How to Use This Repository

1. Start with [Volume 1: Computer Fundamentals](volumes/01-computer-fundamentals.md) and learn the runtime foundations.
2. Move through JavaScript, browser internals, DSA, React, architecture, system design, and interview mastery in order.
3. For every chapter, use the same mastery loop:
   - Read the concept and mental model.
   - Rebuild the examples without looking.
   - Answer the interview questions aloud.
   - Complete the exercises and projects.
   - Teach the topic to someone else or write your own summary.

## Master Roadmap

```text
Computer hardware/runtime
  -> OS process/thread/memory
  -> JavaScript engine execution
  -> Browser event loop + rendering
  -> DOM/CSSOM/network/security
  -> Data structures and algorithms
  -> React component model
  -> React Fiber/concurrency
  -> State/server-cache patterns
  -> Performance/testing/accessibility
  -> Architecture/system design
  -> Interview mastery and teaching
```

## Universal Expert Checklist

For every topic, you should be able to explain:

- What it is.
- Why it exists.
- What problem it solves.
- How it works internally.
- How to use it correctly in production.
- How it fails under edge cases.
- How to debug and optimize it.
- How to teach it with a simple analogy.
- How it appears in interviews.
